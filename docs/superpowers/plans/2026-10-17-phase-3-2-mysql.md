## Context

Phase 3.1 (SQLite) đã merge (`40cde54`). Theo [implementation-phases.md](../../implementation-phases.md) mục 11, phase tiếp theo là **3.2 MySQL/MariaDB**: thêm adapter network relational dùng `go-sql-driver/mysql`, mapping database-as-schema, metadata/paging/filter/sort theo dialect, Save có NULL-safe concurrency và affected-row rõ ràng (tắt Save khi engine không có transaction), SQL tab với parser riêng và fallback chạy vùng chọn.

Mục tiêu: người dùng tạo kết nối MySQL/MariaDB qua bước chọn loại sẵn có, duyệt database → tables/views, xem/lọc/sort/phân trang, sửa ô + Save/Revert an toàn, chạy SQL — với cùng hợp đồng `database.SQLAdapter` + `SQLSessionFactory` như PostgreSQL/SQLite, không hồi quy hai engine kia.

**Quyết định của người dùng (2026-10-17):**
- Ô Database **tùy chọn**: chỉ là database mặc định (SQL tab, auto-mở trong explorer). Explorer liệt kê mọi database user thấy được như "schema", **ẩn** `information_schema`, `performance_schema`, `mysql`, `sys`.
- Hỗ trợ chính thức **MySQL 8.0+ / MariaDB 10.6+**; bản cũ hơn vẫn kết nối nhưng hiện cảnh báo "chưa kiểm thử".

**`internal/database/mysql/connect.go`, `errors.go`** (package mới `mysql`, import driver bằng alias `gomysql`):
- `buildConfig(p, password) (*gomysql.Config, error)`: dùng `gomysql.NewConfig()` rồi `gomysql.NewConnector` + `sql.OpenDB`, **không** dùng chuỗi DSN, để mật khẩu không lọt vào chuỗi lỗi.
  - Cấu hình: `Net=tcp`, `Addr=host:port`, `DBName=p.Database`, `Timeout=ConnectTimeoutSec`.
  - Tham số: `ParseTime=false`, `InterpolateParams=false`, `MultiStatements=false`, `ClientFoundRows=true` (số dòng **khớp** chứ không phải số dòng **đổi**), `AllowAllFiles=false`, `AllowCleartextPasswords=false`, `AllowOldPasswords=false`, charset `utf8mb4`.
  - `AllowPublicKeyRetrieval` chỉ bật khi TLS=disable, để `caching_sha2_password` dùng được khi không có TLS.
- TLS: `tls.Config` gắn vào config của từng profile, **không** dùng `RegisterTLSConfig` toàn cục, không bao giờ dùng `preferred`.
  - `disable` → không TLS.
  - `require` → `InsecureSkipVerify`.
  - `verify-ca` → `InsecureSkipVerify` + `VerifyPeerCertificate` tự kiểm chain bằng RootCAs, không kiểm hostname.
  - `verify-full` → RootCAs + `ServerName`.
  - RootCAs lấy từ file PEM `TLS.RootCert`, hoặc system pool khi không có file.
- Pool: `MaxOpen/MaxIdle` từ profile (+ `query.MaxSessionsPerProfile` cho SQL tab như SQLite), `SetConnMaxLifetime`/`SetConnMaxIdleTime` ngắn (vd. 5 phút / 1 phút) để thấp hơn `wait_timeout`.
- `Connect`: ping và đọc `VERSION()`, `@@version_comment`, rồi lưu `serverInfo{flavor MySQL|MariaDB, major, minor, noBackslashEscapes}` vào Adapter. Dưới MySQL 8.0 / MariaDB 10.6 vẫn kết nối nhưng có cảnh báo (`Adapter.Warning()`, hiện ở status/explorer nếu có chỗ sẵn; nếu chưa có thì ghi trong placeholder thông tin kết nối).
- `classify(ctx, err, doing)`: map `*gomysql.MySQLError` theo mã:
  - 1045 → `KindAuthentication`
  - 1044/1142/1143/1227 → `KindPermission`
  - 1049 → `KindConnection` "Unknown database"
  - 1064 → `KindSyntax`
  - 1205/1213 → `KindConflict` hoặc lỗi lock rõ ràng
  - 2003/2005/2013, `driver.ErrBadConn`, net errors → `KindConnection`
  - ctx → `KindCanceled`/`KindTimeout`
  - Lỗi TLS/x509 → `KindConnection` với Hint.
  - Không bao giờ in mật khẩu/DSN.

**`mysql/catalog.go`** (đọc từ `information_schema`; `TableRef{Schema: db, Name: t}`, Catalog rỗng):
- `ListSchemas`: `SCHEMATA` trừ 4 database hệ thống, sắp theo tên.
- `ListTables`: `TABLES` (`BASE TABLE`→Table, `VIEW`→View, `SYSTEM VERSIONED`→Table kèm Subtype). Kèm `ENGINE`, `TABLE_ROWS` (ước lượng).
- `DescribeTable`:
  - Columns lấy từ `COLUMNS`. Lỗi đọc columns thì cả call lỗi.
  - Mỗi section còn lại ghi trạng thái riêng: constraints (`TABLE_CONSTRAINTS` + `KEY_COLUMN_USAGE` + `CHECK_CONSTRAINTS`), FK ra/vào (`REFERENTIAL_CONSTRAINTS` + `KEY_COLUMN_USAGE`), indexes (`STATISTICS`; prefix index/functional index → `KeyColumns=nil`), triggers (`TRIGGERS`).
  - Ghi chú giới hạn: `information_schema` chỉ trả về đối tượng user có quyền, nên "rỗng" có thể nghĩa là không có quyền. Nêu điều này trong `Reason` hoặc tài liệu.
  - Transaction: theo `ENGINES.TRANSACTIONS='YES'` (không dùng danh sách tên cứng). Engine không có transaction (MyISAM/MEMORY/Aria…) thì `TableMetadata.ReadOnly` = "Engine X does not support transactions; Save is disabled".
- `mysql/values.go` `classOf(dataType, columnType)`:
  - Số nguyên `tinyint/smallint/mediumint/int/bigint` → ClassNumber, `IntBits` 8/16/24/32/64, `Unsigned` từ `COLUMN_TYPE`. `TINYINT(1)` vẫn là Number, không Bool.
  - `decimal/float/double` → Number. `year` → Number.
  - `char/varchar/text*/enum/set` → Text.
  - `date/datetime/timestamp/time` → DateTime.
  - `json` → JSON; MariaDB JSON (longtext + `CHECK json_valid`) → JSON nếu phát hiện được, không thì Text.
  - `binary/varbinary/blob*/bit` → Binary; `geometry*` → Other.
  - `EXTRA`: chỉ `VIRTUAL GENERATED`/`STORED GENERATED`/`PERSISTENT` → `Generated`. `DEFAULT_GENERATED` và `on update CURRENT_TIMESTAMP` thì **không**. `auto_increment` → `IdentityByDefault`.
- `toValue`: chuỗi hiển thị **giống nhau** dù giá trị đến từ text protocol (không có args) hay binary protocol (có args).
  - `[]byte` → text theo class.
  - `int64/uint64` → số thập phân đầy đủ chữ số.
  - `float32`/`float64` → định dạng ngắn nhất, chính xác theo đúng độ rộng của kiểu.
  - Ngày zero `0000-00-00`, `TIME` > 24h, phần giây lẻ giữ nguyên dạng text.

**`mysql/sql.go`, `page.go`** (theo `postgres/sql.go`):

## Phần C — Save/Revert (Checkpoint C)

**`mysql/save.go`** (theo `sqlite/save.go`: `ValidateChanges` trước, build mọi statement trước khi BEGIN, `commitGate`, không retry):
- Mỗi dòng chạy `UPDATE t SET c=? WHERE <key> <=> ? AND <điều kiện giá trị cũ>`.
- Giá trị cũ so sánh **chính xác, NULL-safe**:
  - Text dùng `col <=> ? AND BINARY col = BINARY CONVERT(? USING <charset của cột>)`, tránh conflict bị bỏ qua do collation `_ci`/PAD SPACE và tránh conflict giả khi charset khác (latin1).
  - Số dùng giá trị bind theo kiểu: int64/uint64, decimal dạng string, FLOAT bind `float64(float32)` để so bằng chính xác.
  - NULL dùng `col IS NULL`.
  - Charset của cột lấy từ metadata (`COLUMNS.CHARACTER_SET_NAME`), lưu nội bộ trong adapter, không thêm field shared nếu không cần.
- Kết quả: affected = 0 → `KindConflict`; > 1 → unsafe; cả hai rollback toàn bộ (cần `ClientFoundRows`).
- Chặn coercion im lặng: session của Save đặt `SET SESSION sql_mode` thành strict (`STRICT_ALL_TABLES` + mode hiện tại) trên chính connection của transaction (`db.Conn`). Nếu `SHOW WARNINGS` có cảnh báo thì rollback. SQL tab không bị đổi sql_mode.
- Engine không có transaction hoặc bảng ReadOnly: từ chối trước khi BEGIN.
- Lỗi lúc COMMIT do mất kết nối hoặc timeout → `SaveUnknown`. Lỗi server rõ ràng (1213 deadlock, 1205 lock wait) → biết chắc là chưa ghi.

**Tests (integration):**

- `TestSaveConflictCaseOnlyChange` (collation `utf8mb4_0900_ai_ci` và `general_ci`: 'abc' bị đổi thành 'ABC' phải báo conflict)

## Phần D — SQL tab (Checkpoint D)

**`mysql/statement.go`** `SelectMySQLSQL(in) (SQLSelection, error)`, cùng ngữ nghĩa với `SelectSQLiteSQL`: ưu tiên vùng chọn, không thì statement tại con trỏ. Scanner xử lý:
- Chuỗi `'…'` và `"…"` có backslash escape (tắt escape khi `noBackslashEscapes`), quote nhân đôi.
- Backtick, `#` comment, `-- ` (chỉ khi theo sau là khoảng trắng), `/* */`, `/*! … */`.
- Khối `CREATE … PROCEDURE|FUNCTION|TRIGGER|EVENT … BEGIN … END` có lồng `BEGIN/END`, `IF … END IF`, `CASE … END CASE`, `LOOP/WHILE/REPEAT … END …`. Nếu không chắc thì dùng fallback: người dùng chọn cả khối để chạy.
- Dòng `DELIMITER`: **từ chối rõ ràng** bằng `KindValidation` "DELIMITER is a mysql client command; select the routine body and run it instead".

**`mysql/sql_session.go`, `sql_execute.go`** (theo `sqlite/sql_session.go`):
- Mỗi phiên dùng một `db.Conn` riêng. Statement chạy lần lượt, không args (text protocol). Kết quả giới hạn theo hằng số ở `sql_execution.go`.
- `RowsAffected` lấy từ `Result`. Lỗi gắn với statement. `SHOW WARNINGS` → `Notices` (có giới hạn).
- Trạng thái giao dịch: **chưa chốt cơ chế**. Trước khi code, kiểm trên cả hai server xem có chỉ báo đáng tin không: `@@in_transaction` (MariaDB 10.? / MySQL 8.0.?), `@@autocommit`, `information_schema.INNODB_TRX` theo `CONNECTION_ID()`. Không dựa vào việc parse BEGIN/COMMIT.
  - Có chỉ báo đáng tin thì dùng nó.
  - Không có thì báo trạng thái "Unknown" (thêm `SQLTransactionUnknown` nếu cần) và ghi trong tài liệu.
  - MySQL không có trạng thái "transaction failed". Deadlock 1213 làm rollback cả transaction và trả về Idle.
- Cancel: gửi `KILL QUERY <connection_id>` từ một connection khác của pool (có timeout) **trước khi** hủy ctx, để giữ phiên và transaction. Nếu driver vẫn đóng connection thì trạng thái là `SQLSessionLost`; transaction mở bị server rollback; UI báo rõ.
- `Close` rollback transaction đang mở và trả connection.

**Kiểm tra UI:** `internal/ui/sql_editor.go` (chỗ hiện target) dùng `Profile.Target()`; không còn chỗ nào gắn cứng PostgreSQL.

**Tests:**
- Unit `statement_test.go`: các case scanner ở trên, cùng `DELIMITER` bị từ chối và khối procedure lồng nhau.
- Integration:
  - `TestExecuteSelectBounded`, `TestExecuteWriteAffectedRows`, `TestBeginCommitAcrossRuns`
  - `TestDDLImplicitCommitState`, `TestDeadlockRollsBackState`
  - `TestCancelLongQueryKeepsOrLosesSessionClearly` (`SELECT SLEEP(30)`)
  - `TestCloseRollsBack`, `TestCreateProcedureSelectedBlock`

**Checkpoint D:** chạy SQL vùng chọn hoặc tại con trỏ, Cancel, BEGIN/COMMIT, procedure bằng cách chọn khối.
